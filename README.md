# Java Full Stack Web Development Internship – Task 1

## Project Title
Modern Landing Page with Contact Form (Spring Boot Backend)

---

## Project Description
This project is a simple full-stack application developed as part of the Java Full Stack Web Development Internship.

The frontend consists of a modern landing page with a contact form created using HTML and CSS.  
The backend is built using Java Spring Boot, which handles form submissions using a POST request and prints the submitted data in the console.

---

## Tech Stack
- HTML
- CSS
- Java
- Spring Boot
- Maven

---

## Features
- Modern landing page UI
- Contact form with Name, Email, and Message
- Spring Boot backend integration
- POST request handling using Controller
- Console output for submitted form data
- Success page redirect after form submission
