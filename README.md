# Java Full Stack Web Development Internship – Task 1

## Project Title
Modern Landing Page with Contact Form (Spring Boot Backend)

---

## Project Description
This project is a simple full-stack application developed as part of the Java Full Stack Web Development Internship.

The frontend consists of a modern landing page with a contact form created using HTML and CSS.  
The backend is built using Java Spring Boot, which handles form submissions using a POST request and prints the submitted data in the console.

---

## Tech Stack
- HTML
- CSS
- Java
- Spring Boot
- Maven

---

## Features
- Modern landing page UI
- Contact form with Name, Email, and Message
- Spring Boot backend integration
- POST request handling using Controller
- Console output for submitted form data
- Success page redirect after form submission

---

## Project Structure
## Project Structure
- `src/main/java/com/example/demo/`
  - `DemoApplication.java` – Spring Boot application entry point
  - `ContactController.java` – Handles contact form POST requests

- `src/main/resources/static/`
  - `index.html` – Landing page
  - `contact.html` – Contact form page
  - `success.html` – Success page after form submission
  - `style.css` – Styling for the frontend
  - `script.js` – Client-side scripting
  - `easy-service.png` – Logo / image asset

- `src/main/resources/`
  - `application.properties` – Application configuration

- `pom.xml` – Maven dependencies and project configuration
## How to Run the Project
1. Clone the repository
2. Open the project in an IDE (IntelliJ / Eclipse / VS Code)
3. Run `DemoApplication.java`
4. Open a browser and visit:
   http://localhost:8080

---

## Output
- Landing page loads successfully
- Contact form accepts user input
- Form data is submitted using POST request
- Submitted data is printed in the Spring Boot console
- User is redirected to a success page after submission
